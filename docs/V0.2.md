# Inkwell Roadmap (Internal — v0.1.5 & v0.2)

## v0.1.5 — Long Context & Sub-25 ms Decode
- **Compressed KV cache (FP8 / K4V2)** to fit 32k and 64k context cleanly inside 6 GB VRAM (GTX 1060).
- **Sub-25 ms/tok short-context decode** (currently 27.3 ms/tok bit-exact; attack remaining exposed `moe_ccopy` latency and instruction density).
- **Vision tower inference** (activate the soft `INKWELL_VISION` flag with image encoding support).
- **Native `tokenizer.json` loader** so EXL3 downloads from Hugging Face no longer need a GGUF tokenizer sidecar.

## v0.2 — 8 MB Self-Contained Runtime & Embedded UX
- **8 MB self-contained distribution target**: drop the external 129 MB `libggml-cuda.so` dependency so the full Inkwell download fits under ~8 MB.
- **Built-in Vercel `fx` chat UI** embedded directly with the local model in `inkwell chat` for a rich, lightweight interactive experience.
- **Hugging Face Kernel Hub**: publish standalone Pascal/EXL3 CUDA kernels (`kernels.cu` + `prefill.cu`) via `hf-kernel-builder` + Nix.
